# Company data

Fernway's own data, the kind a support team keeps in its billing system and policy docs.
Fernway, its customers and every address here are fictional.

| File | Contents |
| --- | --- |
| `accounts.json` | 28 customer accounts: plan, status, contact and every charge. Generated by `../fixtures/tools/build_fixtures.py`; edit the data there. |
| `refund-policy.md` | The policy refunds are checked against. |

In the workflow, the account data sits in a script step named "Billing lookup (mock)". In a
real deployment that step would call a database, an API or Data Fabric instead.
