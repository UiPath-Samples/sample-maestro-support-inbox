# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for security problems.

If you find a security vulnerability in this sample code, or in a UiPath product while working through the tutorial, report it privately through the UiPath security disclosure form:

https://www.uipath.com/legal/trust-and-security/report/security-issue

## Scope

This repository contains sample code written to accompany a tutorial. It is not production code and is not covered by UiPath product support or SLAs. Issues such as hardcoded example values or simplified error handling that exist for teaching purposes are not considered vulnerabilities, but we do want to hear about anything that would put a reader who follows the tutorial at risk.
